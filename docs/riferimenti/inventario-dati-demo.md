# Inventario dati demo, inventati e simulati - B&T 2.0

Audit in sola lettura di `app-preview/index.html` (6987 righe) e dei moduli `bt-logic.js`, `bt-weekend.js`, `live-sim.js`, `bt-insights.js`, `bt-ghost.js`, `real-data.js`, `real-weekend.js`. Data audit: 2026-10-04.
Regola del proprietario: gli utenti normali vedono solo dati veri; il simulatore resta solo nel pannello Admin, etichettato DEMO.

Come leggere le tabelle
- "Righe" sono righe di `index.html`, salvo prefisso con il nome del modulo (per esempio `bt-logic.js 202-222`).
- Ultima colonna della Tabella 1: una sola categoria tra queste cinque (testo esatto), seguita da una breve nota dopo il trattino:
  1. `Firestore doc written by the admin`
  2. `OpenF1 session data`
  3. `bundled real 2026 data`
  4. `the user's own saved data`
  5. `hide with an empty-state sentence`
- Ogni riga con `OpenF1 session data` ha implicitamente anche uno stato vuoto: la scelta del progetto ("opzione 3") è niente dati simulati, OpenF1 gratis è bloccato durante le sessioni, i dati arrivano a fine sessione. Senza dati, mostrare una frase vuota (modello già presente nel codice: righe 2581, 2598, 2641, 2645, 2695, 2720, 2735-2736).
- Le frasi tra virgolette sono le stringhe italiane esatte che vede l'utente.
